About

A funny tool, that lives in the terminal.

No windows, no avatars, no history kept forever. One installer sets up the client, and every command fits on one line.

--name
--mes
--act

Type a command

The recipient and the text are passed as flags. No menus, everything on one line.

--names=(bob,alice)

Send to several people

One text to several people at once. If someone is not in the database, the client tells you who. You cannot message yourself.

auto-delete

Messages do not pile up

Conversations stay on the server for a short time and are erased automatically.

device_token

Sign-in by device key

On first launch you enter a name and a password. After that the client recognises you on its own. If the local key is lost, you get access back by signing in with your name and password on the same device.

MarkSetup.exe

One file to install

A Windows installer. Download it, run it, start using it.

  1. Download the installer. The button above takes the file from the latest release on GitHub.
  2. Run MarkSetup.exe. Wait for the installation to finish.
  3. Open the client. On first launch, enter a name and a password.

The installer is not signed with a certificate, so Windows SmartScreen may ask you to confirm the launch.
